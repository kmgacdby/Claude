# QuickDash

一个 Fabric 1.20.6 客户端模组，提供一个类 ClickGUI 面板和三个功能模块。

## 环境

- Minecraft 1.20.6
- Fabric Loader >= 0.15.11
- Fabric API 0.100.1+1.20.6
- Java 21

## 构建

```
./gradlew build
```

产物在 `build/libs/`。本沙盒环境无法访问 Fabric/Mojang 的 Maven 仓库，所以这份代码**没有在本地实际编译验证过**，需要你在自己的开发环境里跑一次 `build` 来发现并修正任何遗留的 API 细节问题（见下方「已知风险点」）。

## ClickGUI 交互

- 按 **Right Shift**（默认，可在原版控制设置里重新绑定）打开/关闭主面板。
- 模块列表：
  - **左键**：开启/关闭该模块
  - **右键**：打开/关闭该模块的详情设置面板（滑条、开关）
  - **中键**：进入按键录制模式，下一次按下的键成为该模块的开关快捷键；按 **ESC** 取消录制
- 每个模块自己绑定的快捷键：按一下开启，再按一下关闭（同一个键是开关，不是两个键）。

## 模块

### 1. 蘑菇煲自动收纳
打开背包（生存物品栏界面）时，按设定的间隔（tick）把背包里的蘑菇煲逐个搬到快捷栏的空位。快捷栏无空位则不执行；副手不算在内。

### 2. 同色方块寻路
持有羊毛/混凝土/陶瓦（含未染色陶瓦，视为白色）时，持续检测并疾跑跳跃前往同色的最近方块（仅扫描玩家所在 Y 层，360 度，可调搜索半径，默认 64，上限 128）。全程接管视角与移动方向，到达后停止移动但模块不会自动关闭。

### 3. 箭矢闪避
持续检测射手拉弓和飞行中的箭矢，预测抛物线并画出轨迹（默认检测范围 32 格，上限 128）。只对预测会命中玩家碰撞箱的最近一支箭做出反应，优先左右横移、必要时叠加前后移动，躲避距离取刚好能躲开的最小距离，不接管视角。可选是否排除自己射出的箭矢（默认排除）。

## 已知风险点 / 需要本地校验

由于沙盒环境无法联网到 Fabric/Mojang Maven 仓库，以下几处是按 1.20.6 (Yarn) 的 API 印象写的，**大概率没问题但请在本地编译时留意**：

- `RenderUtil` 里的世界画线部分（`Tessellator` / `BufferBuilder` / `RenderSystem` 调用链）——1.20.5+ 官方重构了渲染管线，方法签名可能有细微出入。
- `World#isChunkLoaded(BlockPos)`（用于同色寻路的区块加载检测）。
- `RaycastContext` 构造函数最后一个 `Entity` 参数传了 `null`。

其余逻辑（背包槽位映射、模块系统、按键录制、抛物线物理公式）按原版机制实现，风险较低。
